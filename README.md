# Lynx

options monitor for mac

Lynx（猞猁）计划成为面向投资者的独立、本地 Mac App，用于港股和美股期权行情监控，以及现金担保卖出看跌期权（CSP）和备兑卖出看涨期权（CC）的模拟分析。

**当前状态：需求文档阶段，尚未实现 App。** 本仓库目前包含初版 PRD 和许可证，没有可运行程序、安装包或已验证的券商接入。

## 首期产品边界

- 仅支持 Apple Silicon（M1 及以后）的 Mac，不支持 Intel；最低 macOS 版本待确认。
- 首期接入富途 / moomoo。用户自行安装、登录和升级官方 OpenD；Lynx 负责连接引导、连接状态及行情权限检查。
- 仅行情和按一手期权计算的模拟分析；不读取真实现金、持仓或账本，不下单交易。合约乘数取真实合约数据，不固定为 100。
- 每只股票可独立开启 CSP、CC；展示各股票最佳合约及其他合格合约，在四个市场策略列表中分别选出最多三个模拟推荐。
- 数据与偏好保存在本地，不依赖开发者服务器，不做云同步。计划支持手动 / 定时刷新、菜单栏运行和可选通知。
- 券商接入采用 App 内部插件，首期随包提供；不是其他软件的插件，也不提供插件商店。

## 文档与技术方向

[初版产品需求文档（PRD）](docs/PRD.md)记录已确认范围、排序规则、刷新与通知行为、验收标准和待确认事项。

技术栈尚未选定：PRD 比较全 Swift / SwiftUI 与 SwiftUI + 随包 Python 计算进程两条路线。倾向原生 Mac 体验，需先验证 OpenD 接入及计算一致性，再决定是否保留 Python。用户无需自行安装 Python 开发环境是已确认的体验目标。
